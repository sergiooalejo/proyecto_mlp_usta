Este es mi proyecto de MLOps para estimar cuántas bicicletas se alquilan en Seúl durante el día siguiente. Usé el archivo `SeoulBikeData.csv`, revisé sus datos en un notebook y comparé regresión lineal, Random Forest y Gradient Boosting. Random Forest tuvo el mejor resultado de los tres, aunque todavía hay cosas por mejorar.

Para organizar el entrenamiento y las predicciones usé Prefect, y para guardar los modelos y sus resultados usé MLflow. El modelo seleccionado tiene el alias `champion`, que utilizan la inferencia diaria y la API hecha con FastAPI. Los parámetros están en `config/config.yaml` y la inferencia quedó programada para las 06:00, hora de Colombia, mientras los servicios y el proceso de despliegue estén activos.

El análisis y los entrenamientos están en `notebook/`, los flows en `Infraestructure/flows/` y la API en `Infraestructure/api/`. Las instrucciones para probar la API están en su [README](Infraestructure/api/README.md). Como los datos son históricos, por ahora se predice el día siguiente al último registro del CSV. La carpeta `_actividad-2/` es solo material de referencia.
